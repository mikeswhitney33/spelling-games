# Shipping Spell It! to the App Store

The native iOS app lives in [ios/](../ios/) — a SwiftUI project generated by
[XcodeGen](https://github.com/yonaskolb/XcodeGen) from `ios/project.yml`.

## Build locally

```bash
npm run generate:swift        # regenerate WordData.swift after word-list edits
cd ios && xcodegen generate   # regenerate SpellIt.xcodeproj after project.yml edits
open ios/SpellIt.xcodeproj
```

Or from the CLI:

```bash
cd ios && xcodebuild -project SpellIt.xcodeproj -scheme SpellIt \
  -destination 'platform=iOS Simulator,name=iPhone 17' build
```

## One-time setup before submission

1. **Apple Developer Program** — enroll at developer.apple.com ($99/yr).
2. **Bundle ID** — currently `com.mikewhitney.spellit` (set in
   `ios/project.yml`). Change it there if you want a different one, then
   re-run `xcodegen generate`. Register the ID in your developer account
   (Xcode's automatic signing does this for you on first archive).
3. **Signing** — open the project in Xcode → Signing & Capabilities → pick
   your team. `CODE_SIGN_STYLE` is already Automatic.
4. **App Store Connect** — create the app record with the same bundle ID.

## Archive & upload

In Xcode: Product → Archive → Distribute App → App Store Connect. (Or
`xcodebuild archive` + `xcrun altool`/Transporter if you prefer CLI.)

## App Store metadata suggestions

- **Name**: Spell It! — Spelling Games for Kids
- **Subtitle**: Twelve playful spelling games, K–6
- **Category**: Education (primary), Word Games (secondary)
- **Age rating**: 4+ (no objectionable content)
- **Description**: lead with the twelve games, four grade bands, the daily
  challenge with streaks, and — importantly — *no accounts, no ads, no
  tracking, fully offline*.

## Kids Category (recommended)

The app is a natural fit for the Kids Category (5 & Under / 6–8 / 9–11):

- ✅ No third-party analytics or advertising SDKs — the app links no
  networking code at all.
- ✅ No external links, no purchases, no social features.
- ✅ No data collection of any kind → App Privacy answer is simply
  **"Data Not Collected."**
- ✅ COPPA-safe by construction: everything (grade choice, daily streak)
  lives in `UserDefaults` on the device.

Opt in under App Store Connect → App Information → Age Rating / Kids
Category.

## Review notes to include

- The word "misspellings" shown in games (Spot the Word, Fix the Sentence)
  are machine-generated but filtered against a dictionary-derived guard and
  a blocked-words list so no real or inappropriate word ever appears as a
  "fake spelling" — see `scripts/generate-real-word-guard.ts` in the repo.
- Speech is Apple's on-device `AVSpeechSynthesizer`; no audio is recorded.

## Keeping app + website in sync

Word lists, sentences, ending tasks, and both safety lists are generated
into `ios/SpellIt/Generated/WordData.swift` from the TypeScript sources.
After editing `lib/words.ts` (or endings/blocked lists), run:

```bash
npm run generate:guard && npm run generate:swift
```

and commit the regenerated files.
